# Epoch AI data snapshot

Downloaded on 2026-07-29 from Epoch AI's official dataset endpoints for the
Level Grind AI data-center / AI-capex research pilot.

## Sources

- AI Data Centers: https://epoch.ai/data/ai-data-centers
- AI Data Centers documentation: https://epoch.ai/data/data-centers-documentation
- AI Chip Owners: https://epoch.ai/data/ai-chip-owners
- Machine Learning Hardware: https://epoch.ai/data/machine-learning-hardware

## Directory layout

- `raw/`: files exactly as downloaded from Epoch AI.
- `extracted/`: CSV files extracted from the official ZIP packages, plus the
  standalone machine-learning hardware CSV.
- `MANIFEST.md`: file inventory, row counts, checksums, and research-granularity
  mapping.
